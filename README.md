# エンジニアのための自己管理入門 ─ 章構成マップ

書籍『[エンジニアのための自己管理入門](https://www.shoeisha.co.jp/book/)』（翔泳社・2026年6月24日発売／小田中育生 著）の
章構成を、クリックして辿れるマップにしたものです。

**公開URL**: https://ikuoodanaka.github.io/self-management-book-map/

## これは何か

この本は、頭から順に読む本ではなく **いま一番痛いところから開く本** です。
そのため「目次を眺める」よりも「自分の症状から章を選ぶ」ほうが早い。
そこを一枚で見せるためのページです。

- 中央に「自分のハンドルを握る」を置き、その周りに第1〜5章を放射状に配置
- 章をクリックすると、キャッチ・リード文・**こんなときに開く**・**この章で扱うこと**・キーワードを表示
- 前後に「はじめに」「終章」「巻末付録」

## 章構成

| | 章 | キャッチ |
|---|---|---|
| はじめに | セルフマネジメントがキャリアをつくる | なぜ、いま自己管理なのか |
| 第1章 | モチベーションマネジメント | ワクワクを燃料に、成長ループを回す |
| 第2章 | タスク・タイムマネジメント | 余白をデザインする技術 |
| 第3章 | アンガー・ストレスマネジメント | ゴキゲンと、しなやかな回復力 |
| 第4章 | スキルマネジメント | 学び続ける姿勢を整える |
| 第5章 | キャリアマネジメント | 羅針盤を片手に、自分の旅路を歩む |
| 終章 | セルフマネジメントがチームを強くする | 「個」を整えると、チームが動き出す |
| 巻末付録 | 読後30日アクションプラン | 読んで終わりにしないための30日分 |

各章末に「エンジニア視点 / マネージャー視点」のTipsを収録しています。

## 動かし方

ビルド不要・依存ゼロの単一HTMLです。

```
open index.html
```

`index.html` をブラウザで開くだけで動きます。
